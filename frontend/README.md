# Malek Larif Portfolio

This folder contains the React frontend for the Malek Larif portfolio website.

The application uses React 19, Vite, Tailwind CSS 4, Framer Motion, GSAP, Lenis, React Router, React Hook Form, and react-to-print.

## Local development

```bash
npm install
npm run dev
```

## Build and lint

```bash
npm run build
npm run lint
```

The site is configured for Vercel deployment. See the [repository README](../README.md) for the project overview.
